# Arduino Button → Browser Interaction

A simple experiment in connecting physical buttons to actions on a computer screen.

**Press a button on an Arduino and something happens in a web browser:**
a large number appears, the background changes colour, and a short sound plays.

The aim was to make a direct, playful interface between physical inputs and a browser-based visual response, using an Arduino and a single HTML file rather than a separate desktop application.

## What it does

- Connects up to five physical push buttons to an Arduino.
- Sends button presses to a web page over USB.
- Displays a corresponding number (1–5) on screen.
- Changes the background colour for each button.
- Plays a different short musical tone for each button.
- Returns to a neutral screen displaying 0 when no button is pressed.

## AI-assisted development

This project was developed through an iterative, AI-assisted coding process. The Arduino sketch and browser application were generated and refined with generative AI in response to human-directed ideas, testing and adjustments.

It is shared as a working experiment and starting point for further creative development.
